☁️ Облачная база данных в твоем репозитории GitHub (ПК ↔ Телефон) Не подключено
Так как GitHub Pages — это статический хостинг, по умолчанию браузер хранит данные в своем локальном кэше (localStorage). Подключи свой токен GitHub ниже, и приложение будет автоматически сохранять и читать твои данные напрямую из файла dc-state.json в твоем репозитории!
Где взять токен за 30 секунд: на GitHub нажми на свою аватарку (справа вверху) → Settings → в самом низу слева Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic). Поставь галочку repo, нажми Generate и вставь скопированный код (начинается на ghp_...) в поле выше на ПК и на телефоне. Сам токен хранится только у тебя в браузере.
